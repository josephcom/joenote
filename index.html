JoeNote

Store notes in a GitHub repository

Every save, delete and pasted image becomes a commit. What you see here is exactly what is in the repo — from any browser, any machine.

How to make the token (1 minute)
  1. Open github.com/settings/personal-access-tokens/new.
  2. Repository access → Only select repositories → pick this one repo.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Generate, copy, paste it above.

The token is kept in this browser's local storage and sent only to api.github.com. JoeNote has no server. Scope it to the one repo so it can do nothing else, and revoke it any time on GitHub.

Logic

  • a b — both (implicit AND)
  • a AND b · && · &
  • a OR b · || · |
  • NOT a · !a · -a
  • (a OR b) AND !c

Wildcards

  • proj* — any run of characters
  • te?t — exactly one character
  • "exact phrase" — literal, no wildcards

Fields

  • #work / tag:work — #work or anything under it
  • tag:=work — exactly #work
  • near:work — #work, its siblings and their children
  • title: text: file:
  • is:untagged has:image has:link has:code
